# UsersRoleManagementSystem

This project is built using **Angular 19.0.0** and **Node.js 22.13.0**.

## Prerequisites

Make sure you have the following installed before setting up the project:

- **Node.js 22.13.0** (Download from [Node.js official site](https://nodejs.org/))
- **Angular CLI 19.0.7** (Install globally using `npm install -g @angular/cli`)
- **Git** (Download from [Git official site](https://git-scm.com/))

## Setup & Run

1. **Clone the repository**

   ```bash
   git clone https://github.com/sagungiri/users-role-management-system.git
   cd UsersRoleManagementSystem
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**

   ```bash
   ng serve
   ```

   Open [http://localhost:4200/](http://localhost:4200/) in your browser.

For more details, visit the [Angular CLI Documentation](https://angular.dev/tools/cli).
